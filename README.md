# 🏡 Ames Housing Price Prediction App

An end-to-end Machine Learning web application built using **Python**, **scikit-learn**, and **Streamlit** to predict house prices based on the Ames Housing dataset features.

## 🔗 Live Demo
Check out the live web application here: [Ames Housing Price Predictor](YOUR_STREAMLIT_URL_HERE)

## 📌 Project Overview
- **Data Preprocessing & Cleaning:** Handled missing values, encoded categorical features, and scaled numerical attributes.
- **Machine Learning Model:** Trained a **Random Forest Regressor** to achieve accurate price predictions.
- **Interactive Web App:** Designed a user-friendly UI using **Streamlit** allowing users to input house specifications and get real-time price estimations.

## 🛠️ Tech Stack
- **Python**
- **Pandas & NumPy** (Data Manipulation)
- **Scikit-Learn** (Machine Learning Model)
- **Streamlit** (Web Application & Deployment)

## 📂 Repository Structure
- `part1.ipynb`: Jupyter Notebook for data processing and model training.
- `part2.py`: Main source code for the Streamlit web app.
- `rf_model.pkl`: Serialized Random Forest model.
- `requirements.txt`: Required dependencies for deployment.
